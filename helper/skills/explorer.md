- Jump to a folder directly: press `ctrl+l` (or `alt+d`) to focus the address bar, type the full folder path, and press `Return`. Do not double-click through folders one level at a time.
- For simply listing, copying, moving, or renaming files, shell tools are faster and more exact; operate File Explorer only when the user wants to see the folder window on screen.
- Shortcuts: `win+e` open new Explorer window; `ctrl+l` address bar; `ctrl+e` or `ctrl+f` search box; `alt+Up` parent folder, `alt+Left` / `alt+Right` back / forward; `ctrl+shift+n` new folder; `F2` rename; `Delete` move to Recycle Bin; `ctrl+c` / `ctrl+x` / `ctrl+v` copy / cut / paste; `ctrl+a` select all; `alt+Return` Properties; `F5` refresh; `ctrl+t` new tab, `ctrl+w` close tab.
