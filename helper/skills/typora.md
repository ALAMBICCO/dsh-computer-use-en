summary: Markdown typing behavior, source code mode, shortcuts
---
- Enter long Markdown content with `type`: paragraphs are pasted cleanly so headings, lists, and code blocks render as intended.
- Typing Markdown symbols key-by-key triggers auto-pairing (`**` becomes `****`, brackets auto-close, lists auto-continue), so prefer streaming `type` over manual character-by-character symbol entry.
- Press `ctrl+/` to toggle Source Code Mode to inspect or edit raw Markdown.
- Save: `ctrl+s` opens the Save As dialog on a new file; press `alt+n`, `ctrl+a`, type the full file path, and press `Return`.
- Shortcuts: `ctrl+n` new; `ctrl+s` save, `ctrl+shift+s` Save As; `ctrl+1…6` Heading 1…6, `ctrl+0` paragraph; `ctrl+b` / `ctrl+i` bold / italic; `ctrl+shift+k` code block, `ctrl+shift+m` math block, `ctrl+t` table, `ctrl+k` link; `ctrl+f` find, `ctrl+h` replace; `ctrl+Home` / `ctrl+End` top / bottom; `ctrl+shift+l` toggle sidebar.
