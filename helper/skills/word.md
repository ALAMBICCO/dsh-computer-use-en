app: Word
match: Word, winword.exe
summary: New document, formatting, Save As, shortcuts
---
- On the start screen after launch, click "Blank document" (or press `Return`) to open a new document.
- Save As: press `F12` to open the classic Save As dialog directly, press `alt+n` to focus the File name box, `ctrl+a`, type the full path (e.g., `C:\Users\<user>\Desktop\Title.docx`), and press `Return`. Do not click through folders in the left pane or triple-click the file name box.
- Typing: lines starting with `1.` trigger auto-numbering and indentation on `Return`; press `ctrl+z` immediately after `Return` to undo auto-numbering if unwanted, or `ctrl+a` then `ctrl+q` to clear paragraph formatting.
- Heading formatting: `ctrl+Home` to start, `shift+End` to select the line, `ctrl+b` bold, `ctrl+]` to increase font size, `ctrl+e` to center. Avoid clicking the ribbon font-size box while text is selected.
- Use `ctrl+f` to open the Navigation search pane and `Escape` to close it.
- Shortcuts: `ctrl+n` new; `ctrl+s` save; `F12` Save As; `ctrl+z` / `ctrl+y` undo / redo; `ctrl+b` / `ctrl+i` / `ctrl+u` bold / italic / underline; `ctrl+e` / `ctrl+l` / `ctrl+r` / `ctrl+j` center / left / right / justify; `ctrl+]` / `ctrl+[` increase / decrease font size; `ctrl+alt+1` / `2` / `3` Heading 1 / 2 / 3, `ctrl+shift+n` Normal style; `ctrl+Return` page break; `ctrl+Home` / `ctrl+End` start / end of document; `shift+End` select to end of line, `ctrl+shift+Down` select to end of paragraph, `ctrl+a` select all; `ctrl+f` find, `ctrl+h` replace; `ctrl+q` clear paragraph formatting, `ctrl+space` clear character formatting; `ctrl+w` close document.
- Native equations: Insert → Equation, enter linear format (e.g. `dy/dx=-(F_x)/(F_y)`, `x^2`, `\sqrt(x)`, `\sum_(i=1)^n a_i`), then click "Professional" on the Equation tab.
