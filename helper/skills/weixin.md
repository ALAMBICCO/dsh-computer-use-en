---
app: WeChat
match: WeChat, 微信, Weixin.exe
summary: Restore from system tray, search chats, save files
---
- Closing WeChat minimizes it to the system tray; restore it with `open_application` rather than starting a second instance (which prompts for login).
- To find a chat or group: click the search box in the top-left corner, type the name, and click the matching result.
- Sending, recalling, or deleting messages is irreversible — ask the user first unless they explicitly requested it.
- Shortcuts: `ctrl+f` search; `Escape` close active popup window.
