- After launch, click "Blank Presentation" on the start screen. Press `ctrl+m` to insert a new slide (reusing the current layout); inside a body text box, `Tab` / `shift+Tab` demotes / promotes outline levels.
- Native equations (do not type math as plain text): place the caret in a text box → Insert tab → Equation (`π` icon on the far right). Use `type` to enter linear format with parentheses around numerators and denominators, then click "Professional" in the Equation tab's Conversions group to format the entire equation natively.
  - Examples: `dy/dx=-(F_x (x,y))/(F_y (x,y))`, `(\partial F)/(\partial y)\ne 0`, `x^2+y^2=1`, `\sqrt(1-x^2)`, `\sum_(i=1)^n a_i`, `F\in C^1`, `\nabla F=(F_x,F_y)`, `\int_a^b f(x)dx`, `\lim_(x\to 0)`. Follow Greek letters (`\alpha`, `\delta`) with a space.
  - Avoid LaTeX `\frac{}{}`: incremental auto-formatting scrambles it as you type.
  - After finishing an equation, press `End` then `Return` to start a normal paragraph.
- Animations: select the object first. To animate an entire text box by paragraph, press `Escape` inside the text until the box handles appear around the frame, then pick an effect on the Animations tab (Appear, Fade, Fly In, Float In, Wipe).
- Slide transitions: open the Transitions tab, pick an effect (Fade, Push, Morph), and click "Apply To All".
- Inserting images: Insert → Pictures → This Device; in the file dialog press `alt+n`, type the full image path, and press `Return`. If an image covers text, select it and choose Picture Format → Send Backward.
- Save As: `F12` → `alt+n` → `ctrl+a` → type full path (including `.pptx`) → `Return`.
- Shortcuts: `ctrl+m` new slide; `ctrl+d` duplicate selected slide or object; `ctrl+z` / `ctrl+y` undo / redo; `ctrl+b` / `ctrl+i` / `ctrl+u` bold / italic / underline; `ctrl+e` / `ctrl+l` / `ctrl+r` center / left / right align; `ctrl+]` / `ctrl+[` increase / decrease font size; `ctrl+a` select all; `ctrl+g` group; `Page Down` / `Page Up` next / previous slide; `F5` start slide show from beginning, `shift+F5` from current slide, `Escape` end slide show; `ctrl+f` find, `ctrl+h` replace; `ctrl+s` save; `ctrl+w` close presentation.
