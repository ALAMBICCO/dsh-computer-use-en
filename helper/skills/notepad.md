- Windows 11 Notepad uses tabs: `ctrl+n` opens a new tab, `ctrl+w` closes the current tab. Reopening Notepad restores previously unsaved tabs — do not modify or close the user's existing tabs.
- The status bar shows `Ln X, Col Y` and the character count, which you can use to verify that text entry completed.
- Closing a tab with unsaved changes prompts whether to save; choose "Don't save" when the task does not ask to keep the file.
- Shortcuts: `ctrl+n` new tab; `ctrl+shift+n` new window; `ctrl+w` close tab; `ctrl+Tab` switch tab; `ctrl+s` save, `ctrl+shift+s` Save As; `ctrl+f` find, `ctrl+h` replace; `ctrl+g` go to line; `ctrl+a` select all; `ctrl+Home` / `ctrl+End` start / end of document.
