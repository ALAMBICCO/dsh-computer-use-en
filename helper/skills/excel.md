summary: Cell entry, formulas, Save As, shortcuts
---
- Most reliable way to jump to a cell: click the Name Box in the top-left corner (or press `ctrl+g`), type the cell reference such as `B3`, and press `Return`.
- Data entry: press `Return` after typing to move down a row, or `Tab` to move one cell right; separate row values with `Tab` and end the row with `Return` to enter a table block continuously. Press `F2` to edit the active cell.
- Formulas start with `=`, e.g. `=SUM(A1:A10)` or `=AVERAGE(B2:B9)`; press `Return` to confirm or `Escape` to cancel.
- Save As: `F12` → `alt+n` → `ctrl+a` → type full path (including `.xlsx`) → `Return`.
- Shortcuts: `ctrl+Home` jump to A1; `ctrl+End` jump to end of used range; `ctrl+Arrow` jump to edge of data region (hold `shift` to select); `ctrl+a` select current data region; `ctrl+space` select column, `shift+space` select row; `ctrl+c` / `ctrl+v` / `ctrl+x` copy / paste / cut; `ctrl+z` / `ctrl+y` undo / redo; `ctrl+d` fill down, `ctrl+r` fill right; `ctrl+1` Format Cells; `ctrl+b` bold; `ctrl+shift+l` toggle Filter; `ctrl+t` create Table; `alt+=` AutoSum; `ctrl+;` insert current date; `ctrl+Page Down` / `ctrl+Page Up` switch worksheet; `shift+F11` new worksheet; `ctrl+f` find, `ctrl+h` replace; `ctrl+s` save; `ctrl+w` close workbook.
