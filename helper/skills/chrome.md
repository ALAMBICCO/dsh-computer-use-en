- Fastest way to open a URL: press `ctrl+l` to focus the address bar, type the full URL, then press `Return`. Do not click through bookmarks or chains of links when you know the exact URL (e.g., a GitHub repository's PR list is `<repo>/pulls`).
- On long or dense pages, press `ctrl+f` to find text on the page, `Return` / `shift+Return` for next / previous match, and `Escape` to close the find bar.
- To scroll long pages: `Page Down` / `Page Up`, `End` / `Home` for bottom / top, or use `scroll`.
- The user's Chrome usually has many tabs open: press `ctrl+t` to open a new tab for a new task rather than overwriting or closing the user's existing tabs; close tabs you opened yourself with `ctrl+w` when done.
- Leave sign-ins, payments, and CAPTCHAs to the user.
- Shortcuts: `ctrl+t` new tab; `ctrl+w` close tab; `ctrl+shift+t` reopen closed tab; `ctrl+Tab` / `ctrl+shift+Tab` next / previous tab; `ctrl+1…8` switch to tab N; `ctrl+l` address bar; `alt+Left` / `alt+Right` back / forward; `F5` or `ctrl+r` reload, `ctrl+shift+r` hard reload; `ctrl+f` find in page; `ctrl++` / `ctrl+-` / `ctrl+0` zoom in / out / reset; `ctrl+j` downloads; `ctrl+h` history; `ctrl+shift+n` incognito window; `F12` DevTools.
